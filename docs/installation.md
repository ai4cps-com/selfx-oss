# Installation

`selfx` is deprecated as of version 0.1.42. Install the maintained package:

```bash
pip install ai4cps
```

Use `ai4cps` in Python imports, for example:

```python
from ai4cps.dash.dashboard import SelfXDash
```

For existing applications, `pip install selfx` installs `ai4cps>=0.1.42`
and legacy import aliases. Importing `selfx` emits a deprecation warning.
